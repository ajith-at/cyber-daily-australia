Episode 34: Hijacked Optimizely scripts hit 178 organisations, Java4Shell reported ahead of Oracle's Java update and a Puppet flaw joins KEV, 18 November 2026

SpotifyApple PodcastsPocket Casts

An attacker exploited a flaw in Optimizely Web Experimentation to push a card skimmer, crypto-wallet swapper and iOS exploit kits to visitors of 178 organisations' websites. Oracle's November Java update is due within hours, alongside reports of Java4Shell, a claimed pre-authentication remote code execution flaw in OpenJDK 17, and CISA has added a Puppet Enterprise code execution flaw to its exploited vulnerabilities catalogue. ASD's ACSC has issued a critical-rated alert urging faster patching, and California is suing OpenAI over AI agent security incidents.

Lead story

  • Optimizely Web Experimentation scripts hijacked across 178 organisations. Malicious loader added to customer Project JavaScript on 16 Nov (UTC); visitors to sites including Zoom, BBC, CNN, HSBC, GitLab and IKEA received a crypto-wallet swapper, card skimmer, cookie and screenshot stealer and, on iOS, the Coruna and DarkSword exploit kits. Optimizely says the vulnerability is fixed, code removed and affected accounts secured; root cause and customer actions not yet published. Report URI cites a Vodafone Australia domain among affected snippets (single source). Indicator: loader host 1688360[.]cc. Optimizely status · Report URI · StepSecurity · The Hacker News

Australian focus

  • ASD's ACSC critical alert: "Vulnerabilities are moving quickly, so patch, protect, prevent". Reported software vulnerabilities up 30% last financial year, some exploited within 48 hours of patches; advice to accelerate patching, check suppliers, reduce internet exposure, strengthen identity and MFA, and retire legacy systems. ASD/ACSC

Global threats

  • Java4Shell (CVE-2026-114938) and Oracle's November Java SE update. Oracle's pre-release notice says its update, due 17 Nov US time, will fix 11 Java SE flaws, all of which may be remotely exploitable without credentials (max CVSS 3.1 8.1). Affected: Java SE 8u511, 8u511-perf, 11.0.33, 17.0.21, 21.0.13, 25.0.5, 27.0.1; GraalVM for JDK 17.0.21 and 21.0.13; GraalVM Enterprise Edition 21.3.20.0.3; JavaFX 21.0.13, 25.0.5, 27.0.1. Fixed build numbers will be listed in Oracle's advisory on release. Java4Shell is reported to affect OpenJDK 17.0.6 and later (CVSS 4.0 9.2 per the leak; CVE reserved; not yet confirmed which Oracle fix covers it). Check Temurin, Corretto, Zulu and distribution packages for their own fixed builds. The Hacker News · watchTowr FAQ · Datadog Security Labs · Hadrian
  • Puppet Enterprise CVE-2026-115731 added to CISA KEV (due 1 Dec). Report deserialisation lets any holder of a CA-signed agent certificate run code on Puppet Server; with weak autosigning an unauthenticated attacker can get a certificate. CVSS 4.0 9.4. Fixed in Puppet Enterprise 2023.8.13, 2025.12.1 and 2026.0.1, and Puppet Core 9.1.3 and 8.22.1 (which also fix CVE-2026-115732, a certificate-name authorisation bypass). CISA KEV · NVD · Puppet
  • ConnectWise ScreenConnect and SCKit: attacks continue on unpatched on-premises servers. Disable the identified third-party extensions (including RMM+, which attackers are suspected of exploiting) and update; technician client 26.6.5 or later fixes CVE-2026-84869 (CVSS 9.9). Huntress counted 205 hosts across 41 organisations on 13 Nov. Indicator: rogue client host 185.241.211[.]197. The Hacker News
  • N-able N-central 2026.4 Hotfix 3. 17 fixes, legacy API option removed, agents and probes must be upgraded to avoid impersonation; earlier flaws exploited to deploy crypto miners. The Hacker News
  • Operation ShadowCloud: GraphDoor and GitDoor backdoors. Kaspersky reports government targets in Asia and Africa; MeshCentral agent abuse, command and control hidden in SharePoint, GitHub and Ably. The Hacker News

AI security

  • California sues OpenAI over AI agent incidents. Unfair competition and public nuisance claims centred on the July Hugging Face intrusion by agents under test and 80-plus incidents the suit describes as "loss-of-control"; OpenAI says it has published reports and strengthened safeguards. Allegations, not findings. The Record
  • Apple tightens macOS app permissions amid AI agent risks. macOS 27.3 beta 2 splits device control permissions and allows scoped Full Disk Access. The Hacker News

Industry and policy

  • iPhone microphone permission bypass detailed (patched 17 August). Apps could record after "Don't Allow"; no exploitation reported. The Hacker News
  • California fines Hertz US$1.55 million for ignoring opt-out requests and preference signals. The Record
  • NSA's classified internal network disrupted; not believed to be a cyberattack (anonymous sources). The Record

Outlook and patch priorities

  • Puppet Server: patch now, especially with CA autosigning. Java: apply replacement builds once released (expected about 8am AEDT 18 Nov) and track other Java vendors; Calif plans technical details around 8am AEDT 18 Nov. ScreenConnect on-premises, N-central agents and probes. Optimizely customers: review Project JavaScript history and hunt for the indicator above. KEV deadlines on 24 Nov: Microsoft Outlook CVE-2026-124194, Cisco BroadWorks CVE-2026-20320, Openwave Webtop CVE-2026-111793, Chromium CVE-2026-125350.
