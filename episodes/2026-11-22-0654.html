Episode 38, Sunday Special: AI Agents Hacking at Machine Speed, 22 November 2026

SpotifyApple PodcastsPocket Casts

Attackers are now handing a target and a one-line goal to open-source multi-agent penetration-testing frameworks such as Cairn and ARTEX, and letting the harness plan, try, fail and retry around the clock. This Sunday Special walks through Amazon's account of a Cairn operator finding a zero-day in MONAI Label, the wider pattern reported by Unit 42, Google and the FBI, a reality check on failures and noise, and five things defenders should do now. Before the Special, a late item: Microsoft confirmed that an exploited Entra Connect Health flaw exposed tenant administrator contacts and metadata.

Late item: before the Special

  • Microsoft Entra Connect Health flaw exploited to read tenant metadata (late item, added 22 November 2026, about 7am AEDT). Flaw introduced 23 July, found 9 November, fixed server-side 19 November; read-only access to administrator and technical contact emails, tenant IDs, names and domains, licence tier and directory sync status. Microsoft says no passwords, tokens or valid keys were exposed and no customer patch is required; number of affected tenants and attacker not disclosed. Advice: warn admins about targeted phishing, use phishing-resistant MFA for privileged accounts, check Azure Service Health in the portal. BleepingComputer · Neowin

The case: Amazon's Cairn investigation

  • Cairn operator's AI agents found and exploited a MONAI Label zero-day (Amazon Threat Intelligence, 20 November 2026). Exposed, unauthenticated Cairn console found 10 September; campaign from 8 September, about 48 hours, East Asian universities outside mainland China. Two detailed failures (Redis: about 16 hours, 148 actions; GPU server: about 80 usernames, 30,000+ credential combinations over 6+ hours), one success (mapping to arbitrary file write in about 11 minutes; later root reverse shell). China-nexus, moderate confidence (Amazon). Amazon · The Hacker News
  • MONAI Label path traversal, GHSA-qc22-rmgc-vg94 / CVE-2026-133968 (CVSS 3.1 9.8, scored by MITRE; the GitHub advisory does not yet list the CVE). Affected: MONAI Label 0.8.5 and earlier. Patched versions: none listed (checked 22 November 2026, about 6am AEDT); fix merged in source on 19 October (PR #1915) but not yet in a release; the advisory says it will be included in the next MONAI Label release. Workarounds: enable authentication (MONAI_LABEL_AUTH_ENABLE=True), keep off untrusted networks, run as an unprivileged user with write access limited to the datastore. GitHub advisory · CVE record

An ecosystem, not one actor

  • Unit 42: Cairn campaign CL-STA-1238. Customised Cairn fork with Zhipu and DeepSeek models, August to September 2026; 25 operations against at least 19 organisations; access or data at 10, including over a million records at one. China-nexus, moderate confidence. Not linked by either source to Amazon's actor. Unit 42
  • Google Threat Intelligence Group and Mandiant: agentic threat activity crosses a significant threshold (16 November 2026). Names ARTEX, Cairn, CyberStrikeAI and PentAGI; exploit agent doing continuous patch diffing (PHP example); PaperCut flaws exploited as zero-days in late August, then AI-assisted exploits within a day of disclosure and a GreyNoise-observed mass campaign within four days; hundreds of fake, likely LLM-generated proofs of concept. Google Cloud blog
  • FBI FLASH-20261113-001: ARTEX. Open-source Go multi-agent framework released July 2026; original repository pulled October, forks continue. More than 1,600 publicly exposed ARTEX consoles; some intrusions reached privileged access in under three hours; indicators in the alert. FBI IC3
  • Amazon MadPot observations of ARTEX agents. 3 October to 5 November decoys; disparate China-nexus groups (moderate confidence); agents succeeded where basic security hygiene was missing. Amazon
  • Barracuda: anatomy of a machine-speed intrusion. Key given to an AI vendor and never retired; about 10 cloud accounts in roughly 44 hours; indicators match ARTEX (Barracuda). Barracuda
  • Rapid7: likely AI-assisted tooling in an Apache Axis / Confluence intrusion (inferred, not confirmed). Sequential task IDs in commands; database access just over three minutes after first execution; cloud data warehouse at about four hours. Rapid7
  • F6: Cisco Expressway exploitation scripts "possibly developed with assistance from" AI (inferred from code comments). The Hacker News
  • Calif: Java4Shell found with an AI coding agent. About an hour to discover, two more hours to a first working exploit, under US$200 in tokens; "centaur" work. Calif

Five takeaways

  1. Take management and research tools off the internet; require authentication on consoles, dashboards, hypervisors, backup platforms and tools like MONAI Label.
  2. Treat patch release as the start of a race measured in days: internet-facing systems first. ASD's ACSC critical alert, 17 November 2026: Vulnerabilities are moving quickly, so patch, protect, prevent
  3. Remove the easy wins: default and hard-coded credentials, unauthenticated databases and inference endpoints, unretired keys; multi-factor authentication (MFA) everywhere.
  4. Automate first response on high-confidence detections; humans supervise outcomes.
  5. Hunt for the noise: long scripted command runs, credential-guessing bursts, API mapping followed by uploads, published framework indicators (Google, FBI, Rapid7); Mandiant hardening guide via the Google report above.
