Episode 36: Suspected China-linked hackers exploited a vCenter zero-day, exploited LiteLLM and Apache Axis flaws join KEV and an AI pentest tool hits the European Commission, 20 November 2026

SpotifyApple PodcastsPocket Casts

Broadcom has patched a critical VMware vCenter authentication bypass that Google says a suspected China-nexus group exploited as a zero-day in September. CISA has added exploited flaws in Apache Axis, the LiteLLM AI gateway, REDCap and Synology DSM to its KEV catalogue, and the European Commission has confirmed a campaign run with the ARTEX AI penetration testing framework. PHP and Ruby have shipped critical security releases, and Palo Alto Networks is buying Applied Compute.

Lead story

  • VMware vCenter authentication bypass exploited as a zero-day (CVE-2026-123890, CVSS 9.8, VMSA-2026-0009). Authentication bypass in the VMware Directory Service; network access to vCenter is enough; no workaround; reported by Mandiant. Fixed in vCenter 9.1.1.0200, 9.0.2.0200 and 8.0 U3m, and VMware Cloud Foundation 5.2.5; vCenter 7.0 has no public fix (contact Broadcom under extended support); Telco Cloud Platform and Infrastructure per KB463116. Google Threat Intelligence Group says suspected PRC-nexus ARMORY CASTLE (formerly UNC5221) exploited it in early September 2026 with the Golang tool BONESAW (LMDB exfiltration, SAML STS hijack, SSO administrator creation) after entering via BeyondTrust Remote Support zero-day CVE-2026-102764. The advisory also fixes SDDC Manager CVE-2026-123891 (SQL injection, 8.1), CVE-2026-123892 (command injection, 7.2) and CVE-2026-123893 (privilege escalation, 6.7), fixed in 9.1.1.0200, 9.0.2.0100 and 5.2.5, and VMware Tools for Windows CVE-2026-123894 (6.7), fixed in 13.1.5.0 and 12.5.5. Broadcom VMSA-2026-0009 · Google Threat Intelligence

Australian focus

  • Woolworths e-gift cards drained. Customers who bought Everyday WISH digital gift cards during a 4% discount promotion report losses of up to $500; Woolworths apologised, is investigating and offering replacement e-gift cards as a next step, but has not explained the cause or confirmed containment. Experts suggest enumeration or fake balance-check sites; unconfirmed. Reported 18 November. ABC News

Global threats

  • CISA adds four exploited flaws to KEV (18 November, US time). CVE-2026-90436 Apache Axis, CVE-2026-90817 REDCap and CVE-2024-10441 Synology DSM (federal due date 21 November), and CVE-2026-40217 LiteLLM (due 2 December). CISA · The Hacker News
  • Apache Axis CVE-2026-90436 exploited against Confluence Data Center. Unauthenticated class instantiation via a crafted SOAP fault in Axis 1.x through 1.4 (end of life; no fixed release, upstream patch commit only). Rapid7 saw exploitation on 13 November against Confluence with "Remote API (XML-RPC & SOAP)" enabled (off by default), database access within minutes, a cloud data warehouse within four hours and a Microsoft 365 sign-in about twelve hours in; likely AI-assisted tooling. Fix: Confluence 9.2.28 or 10.x, or disable the Remote API; N-able N-central 2026.4 HF3 disables the legacy API. A Metasploit module was released 17 November. Rapid7 · SecurityWeek · oss-security
  • REDCap CVE-2026-90817. Unauthenticated code execution on self-hosted servers via a public survey context (needs a valid public survey hash). Fixed in 16.0.49 LTS, 17.3.10 LTS and 17.4.4 Standard. Rescana
  • NGINX2Root update. Xint names five critical NGINX flaws (CVE-2026-123007, CVE-2026-123633, CVE-2026-123634, CVE-2026-121810, CVE-2026-113425) and chains them with an unpatched Linux kernel SCTP flaw to gain root, including container escape. Rapid7 has published a constrained PoC for CVE-2026-123007. No exploitation reported. Fixed in NGINX Open Source 1.30.7 and 1.31.9, NGINX Plus 37.0.8.1 and 37.3.0.1; restart after upgrading. Help Net Security · iTnews
  • Java4Shell exploitation attempts. GreyNoise recorded over 150 attack-shaped requests from five IP addresses with no successful intrusions seen; watchTowr reports spraying and blind exploitation attempts. SecurityWeek
  • JPMorgan Chase and Mastercard confirm vendor data exposure. JPMorgan says marketing data held by third-party vendors (some names and email addresses) was accessed, unrelated to its outage; Mastercard says a limited number of emails from one benefit program were exposed. Record counts reported by Cybernews are unconfirmed. The Verge

AI security

  • LiteLLM CVE-2026-40217 exploited. Sandbox escape in the POST /guardrails/test_custom_code endpoint gives code execution as root in the default Docker image; requires a proxy-admin credential, which attackers try to guess from defaults. Affected 1.81.8 up to (not including) 1.83.10; fixed in 1.83.10 (the advisory text says 1.83.11, so either is safe); workaround: block the endpoint. Rotate provider keys and replace default master keys. GitHub advisory · Zenity Labs
  • European Commission confirms AI-assisted cyber campaign. Detected 22 October; defenders saw the public AI penetration testing framework ARTEX; Sysper and MyPMO staff systems offline for more than ten days; no evidence of a broad staff data breach and no ransom demand reported. The Register · The Record

Industry and policy

  • PHP security releases fix 18 flaws. PHP 8.5.13, 8.4.28, 8.3.37 and 8.2.36. CVE-2026-129289 PHP-FPM request smuggling (CVSS 9.2) affects front ends that reuse backend connections (nginx fastcgi_keep_conn on, Apache enablereuse=on, HAProxy FastCGI, LSAPI) and an application path that leaves the request body (php://input) unread; others include CVE-2026-129474, CVE-2026-129496, CVE-2026-126714 and CVE-2026-115560 (code execution), CVE-2026-129291 (local privilege escalation) and CVE-2026-128090 (PHAR signature bypass). BleepingComputer · PHP advisory
  • Ruby fixes seven Regexp and String flaws. Ruby 4.0.10, 3.4.13 and 3.3.14, including critical heap buffer overflows. Ruby
  • Palo Alto Networks to acquire Applied Compute. All-stock deal valued at about US$4.5 billion for an open-weight model post-training and inference platform; expected to close in fiscal Q3 2027. Palo Alto Networks
  • US senators urge action on AI-enabled cyber threats. Senators Cantwell and Rounds ask the White House Super Intelligence Task Force for defensive AI deployment and security standards for autonomous agents. US Senate Commerce Committee

Outlook and patch priorities

  • Critical: VMware vCenter (patch; hunt for unexpected SSO administrator accounts; restrict access to 7.0); KEV additions (Confluence with Remote API, REDCap, Synology DSM, LiteLLM with key rotation).
  • High: PHP-FPM with backend connection reuse; NGINX (restart after upgrade); Java runtimes.
  • Routine: PHP and Ruby updates, VMware Tools for Windows, SDDC Manager.
  • Watch: further NGINX and Java4Shell exploit code; Woolworths explanation; ARTEX-assisted activity.
