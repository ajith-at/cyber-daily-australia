Episode 40: Azure API Management flaw exploited against Norwegian energy firms, CrowdStrike to buy Zscaler and abandoned ASP.NET library exploited, 24 November 2026

SpotifyApple PodcastsPocket Casts

Norway's National Security Authority says attackers exploited a now-mitigated flaw in Microsoft's Azure API Management Classic tiers to target stored secrets, hitting Equinor and Skagerak Energi, and customers need to rotate credentials. CrowdStrike has agreed to buy Zscaler for US$43.9 billion in stock. Mandiant reports exploitation of an unpatchable flaw in the abandoned Idunno.AntiCsrf ASP.NET module, and CERT-In warns that payment-workflow fraud has spread beyond finance, as AI-driven attack frameworks appear across sectors.

Lead story

  • Azure API Management (APIM) Classic tiers flaw exploited to target secrets; Equinor and Skagerak Energi affected. Microsoft identified the issue on 18 November and mitigated it on 19 November (non-public advisory, as reported); APIM v2 not affected; Microsoft told The Record affected tiers include Developer, Basic, Standard and Premium. Assume secrets, named values, subscription keys, identity provider client secrets and management tokens stored in APIM are exposed: rotate them, move secrets to Azure Key Vault, review logs, include dev and test instances. NSM patch check (read RuntimeVersion from the instance's internal-status page): 0.52.x is patched if the last number is 31936 or higher; 0.53.x is patched if the last number is 31938 or higher; other patterns (for example 0.53.4608.0 or 0.52.4150.0) indicate v2 or Consumption tiers, which are not vulnerable; lower numbers are still vulnerable. No CVE published. NSM · The Record · The Register · SecurityWeek

Global threats

  • Idunno.AntiCsrf ASP.NET module exploited (CVE-2026-131914, CVSS 9.3), no patch. Affected: Idunno.AntiCsrf.dll version 0.9.1.0 / 0.9.1 Beta. Unauthenticated remote code execution via one HTTP POST. Remove and replace with a supported anti-CSRF control; audit Web.config and bin/ for Idunno.AntiCsrf or AntiCsrfModule; review IIS logs for anomalous POSTs to .aspx returning 302 or 500 with elevated cs-bytes; rotate machineKey, encryption keys and database credentials if exploited. Mandiant MNDT-2026-0048 · The Hacker News
  • ConnectWise ScreenConnect CVE-2026-84869 (CVSS 9.9): mass exploitation attempts (follow-up). Huntress: at least 688,000 guest "run file" requests to 42 servers from 29 IP addresses, 20 October to 16 November. Fixed technician client: 26.6.5 or later. Indicators: batch files update.bat / update_<8 hex>.bat, domain masterdarky[.]com, guest IP 91.224.92[.]167. Huntress · The Hacker News · ConnectWise bulletin
  • N-able Mail Assure SSRF found during breach investigation (CVE-2026-134624, CVSS 4.0 score 9.3) (follow-up). Affected: builds earlier than 20261121.1943; fixed in build 20261121.1943 (vendor-hosted). Entry point not confirmed. N-able advisory · The Hacker News
  • Webworm suspected of using a modified SoftEther VPN Bridge ("NtMonitor VPN"). Rapid7, moderate-confidence attribution; based on SoftEther VPN Bridge version 4.44, build 9807. Rapid7 · The Hacker News
  • Austria's Foreign Ministry: externally run website breached (12 to 13 November); staff names and official contacts exposed. Unattributed. The Record
  • LaLiga: fan-services platform breached (14 to 16 November), personal data extracted. BleepingComputer
  • GlobeTopper: about US$2.5 million lost revenue and US$70,000 in gift cards after an October intrusion; client API credentials rotated. BleepingComputer
  • binary-parser code injection (CVE-2026-134814). Affected: versions before 2.3.1; fixed: 2.3.1. Only when an attacker controls parser definitions. GitHub advisory · The Hacker News

AI security

  • CERT-In: payment-workflow fraud spreads beyond finance; AI-driven agentic attack frameworks seen across sectors (CIAD-2026-0062, 20 November). Altered business records and approval relationships used to push unauthorised transactions through legitimate systems at technology service providers for government-linked payments and payout platforms; no amounts or attribution. Earlier CERT-In advisories (CIAD-2026-0046, CIAD-2026-0049) linked AI-assisted tooling to payment fraud at financial firms. CERT-In advisory · The Hacker News · I4C advisory (PDF)
  • OX Security: prompt injection and tool poisoning in 22% of flagged MCP servers (vendor research). OX Security release
  • Google: Semantic governance policies cut AgentDojo prompt injection success from 48.7% to 0.9% (vendor-reported). Google Developers Blog

Industry

  • CrowdStrike to acquire Zscaler for US$43.9 billion in stock. 1.135 CrowdStrike shares per Zscaler share (US$260.41); about 8,000 Zscaler customers not yet using CrowdStrike (cross-sell target); subject to closing. The Record · CrowdStrike release

Outlook and patch priorities

  • Critical: Azure APIM Classic (rotate secrets, check runtime version); remove Idunno.AntiCsrf; ScreenConnect technician clients to 26.6.5 or later.
  • CISA KEV deadline 24 November (US): CVE-2026-124194 (Microsoft Office), CVE-2026-111793 (Openwave Webtop Media Transcoder), CVE-2026-20320 (Cisco BroadWorks), CVE-2026-125350 (Google Chromium). CISA KEV
  • Watch: public Microsoft APIM advisory and further victims; N-able entry point; regulatory review of CrowdStrike and Zscaler.
