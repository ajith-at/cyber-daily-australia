Episode 26: Attacker rides Qubole's trusted AWS access, GPUStack and FreeSWITCH flaws exploited and a German host breached through its MCP server, 10 November 2026

SpotifyApple PodcastsPocket Casts

An attacker used credentials for Qubole's AWS account to assume the integration roles customers had created for the data platform, then took secrets and S3 data, mostly through roles that showed no other legitimate vendor use that month. CISA added three actively exploited flaws to its KEV catalogue: GPUStack, FreeSWITCH and the OpenSSH *sshole bypass, where researchers now report post-exploitation activity. Vanderbilt University is responding to an active cyber incident, German host Mittwald was breached through its MCP server, and Victorian medical group Epichealth disclosed unauthorised access affecting patient information.

Global threats

  • Qubole cross-account trust abused in customer AWS environments (Wiz, with Sentra and Mandiant, 9 November 2026). Between 14 and 26 October 2026 an attacker used IAM credentials from AWS account 805246085872 (used by Qubole's platform) to AssumeRole into customer integration roles; every request carried a valid External ID and succeeded. Enumeration, Secrets Manager, SSM Parameter Store and Lambda environment variables harvested; TruffleHog used to validate discovered AWS, Entra ID and Okta credentials; S3 exfiltration, sometimes entire buckets. Most abused roles showed no other legitimate vendor AssumeRole activity in October. How the credentials were obtained has not been disclosed. A separate 8 to 11 October set of activity used customer-owned access keys created for Qubole integrations. Hunt from 1 October 2026 for AssumeRole events from 805246085872 from non-AWS addresses, principal IDs AIDA3W7DIFLYOLTK63SFS and AIDAJYRRH5Y3A7AAJM2HW, and session names starting quiam-. Mitigations: remove unused vendor trust, pin trusted principal and add aws:SourceIp or aws:SourceVpce conditions, treat External ID as non-secret, enable S3 data events. Wiz; The Hacker News
  • CISA adds three exploited flaws to KEV (9 November 2026, due 12 November 2026 for covered US federal civilian agencies). CVE-2026-102895 (GPUStack, see AI security), CVE-2026-123158 (OpenSSH *sshole) and CVE-2026-116779 (SignalWire FreeSWITCH). CISA KEV
  • *OpenSSH sshole update (CVE-2026-123158). Now in CISA KEV. GreyNoise observed successful exploitation followed by reconnaissance, attempts to read password hashes and root SSH keys, authorized_keys changes and a command-and-control implant; the attempted credential reads are not confirmed as successful. Fixed in OpenSSH 10.6p2 (restart sshd), or set PasswordAuthentication no. Background in Episodes 23 and 25. GreyNoise; BleepingComputer
  • FreeSWITCH SIP MESSAGE command execution (CVE-2026-116779, CVSS 9.8). An accepted inbound SIP MESSAGE can select the api chat protocol and run FreeSWITCH API commands, including OS commands, as the FreeSWITCH process; stock profiles accept MESSAGE. SignalWire says exploitation has been observed in the wild. Affected: all releases up to and including 1.11.2. Fixed: 1.11.3 (adds enable-chat-api-proto, off by default). Workaround: enable-chat=false on profiles that don't need chat; make sure every directory user has a password (this reduces exposure but does not close the path for a valid account). FreeSWITCH advisory; Ostorlab analysis; Rescana
  • Vanderbilt University active cyber incident (9 November 2026, US time). Incident may affect university devices, systems and cloud services. University asked its community to shut down university devices and disconnect from campus Wi-Fi. BYOD ransomware group listed the university and claims student and employee data (unverified). Vanderbilt; The Record
  • Ethersphere bee-js and Swarm Desktop compromised (9 November 2026). Malicious bee-js 13.3.0 and Swarm Desktop 0.56.2 published through the project's release automation; steal the Swarm Desktop wallet key and password and install a backdoor on Windows, macOS and Linux. Withdrawn; Swarm Desktop 0.56.3 replaces the compromised 0.56.2; researchers recommend rolling back to bee-js 13.2.0 (a pre-incident release). Treat hosts that installed the bad versions as compromised; move funds to a new wallet and rotate secrets from a clean machine. Swarm Desktop release; bee-js 13.2.0; The Hacker News; Ostorlab
  • LNbits tells all operators to shut down servers (8 November 2026). Wave of attacks; one operator reports 2,285,545 satoshis (about 0.023 BTC) withdrawn by new accounts. Developer estimated a fix within 24 to 48 hours on 8 November (upper end about 1am AEDT Wednesday 11 November); the release page still listed 1.6.2 as latest at last check. Watch for an official fixed release and restart guidance. The Hacker News; LNbits releases
  • Bitter deploys PapRAT in South Asia (Fortinet FortiGuard Labs, 2 November 2026). New RAT in C++ and Rust; delivery via LNK abusing ftp.exe and VHDX images with lure spreadsheets. Fortinet

Australian focus

  • Epichealth Medical Clinic cyber incident (notice dated 4 November 2026). Four Victorian clinics (Warrnambool Medicare Urgent Care Clinic, Ocean Grove Marketplace, Ocean Plaza, Portarlington). Information that may be affected: name, date of birth, contact details, Medicare card number, Centrelink CRN, DVA number and health information. Reported to ACSC and OAIC; clinics open. Separately, Cyber Daily reports The Gentlemen listed Epichealth on 31 October; the notice does not attribute the incident or confirm theft. Epichealth notice; Cyber Daily
  • ANZ implementing an enterprise AI control plane (FY26 results, 9 November 2026). Planned centralised visibility, governance and technical control across users, models, agents, tools, costs and platforms, with traceability and limits on agent activity. Underlying software not disclosed. iTnews; ANZ BlueNotes

AI security

  • GPUStack authentication bypass exploited (CVE-2026-102895, CVSS 9.8). Before the fix, a request appearing to come from loopback was treated as the built-in administrator when force_auth_localhost was false (the default), reachable via a same-host reverse proxy or a forged X-GPUStack-Real-IP header. The flaw lets attackers create persistent admin API keys and read worker and cloud-provider secrets; the vendor reports an exploited 2.1.1 deployment where custom inference backends ran reverse shells. Affected: versions before 2.2.0. Fixed: 2.2.0. Workaround: force_auth_localhost=true and strip client-supplied X-GPUStack-Real-IP. Review users, API keys and backends; rotate worker and cloud secrets. GitHub advisory; Ostorlab
  • Mittwald breached through its MCP server (disclosed 7 November 2026). Flaw first tested 21 October, exploited 27 October, detected 4 November; 56 customer projects compromised; MCP server shut down. Mittwald cites speed of activity as indicating AI tool use, with no other evidence offered; unclear whether the flaw was in its own code or open-source libraries. Mittwald (German); The Record
  • BOSSAI: one attacker, twelve configured AI agents, nine active (Acronis TRU, 4 November 2026). Attacker placed in Hualien City, Taiwan; hundreds of targets in at least 11 countries; about 10 accessed in Taiwan, Mexico and Thailand, including Taipei 119 dispatch case records from seven districts. Attack agents ran mostly on locally hosted models with safety training removed after commercial models refused; a scanner invented CVEs and more than half of its high and critical findings were false; in the observed attacks, agents failed where logins were enforced. Acronis; The Hacker News

Industry and research

  • PwnEscape (CVE-2026-99999) turned into a Firecracker escape (pwn.ai, part 2 published 9 November 2026). Host-kernel IPv4 virtio-net/TAP checksum flaw; demonstration used Firecracker v1.16.1 run as root without the jailer. AWS: EC2, Lambda and Fargate not affected. Affected kernels: 4.4 through 6.18 per AWS. AWS bulletin Upstream fix commit 6785011f8b16; patch the host kernel and reboot. Kernel CVE team score 9.3; Red Hat, Amazon and SUSE 8.8. iTnews; pwn.ai

Outlook and patch priorities

  • Critical: GPUStack 2.2.0 plus key and backend review; FreeSWITCH 1.11.3 or enable-chat=false; OpenSSH 10.6p2 plus checks for planted keys and services.
  • High: audit cross-account IAM trust (Qubole customers first); host kernel patch and reboot for self-run KVM/Firecracker; LNbits offline until fixed.
  • Watch: Microsoft November Patch Tuesday (early Wednesday 11 November, Melbourne time); BYOD claims on Vanderbilt; Mittwald's detailed account.
