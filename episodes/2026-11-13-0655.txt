From a Friday morning in Melbourne, this is U51, your cyber and AI security brief for the 13th of November, covering the 24 hours to about six this morning, Melbourne time.

Here are the headlines. An attacker used nearly five thousand hijacked GitHub accounts to plant a secret stealer in the build pipelines of more than eighteen hundred repositories. Attackers with access to cloud-hosted ScreenConnect panels pushed rogue remote access clients to hundreds of managed endpoints. A researcher published new N-central exploits that work against this week's hotfix, and probing started within hours. And the national parks booking breach now reaches Queensland, Victoria and South Australia.

Starting on Tuesday, an attacker used stolen credentials for 4,837 GitHub accounts to test which repositories they could write to, then planted a credential stealer in continuous integration workflows, according to Aikido Security. Aikido says the stealer ran in more than eighteen hundred repositories and took their credentials; a separate count by SafeDep found 8,093 public repositories that received malicious commits, some through an npm install hook that also runs on developers' own machines. The attacker usually reverted the change within minutes and deleted the workflow logs. The stealer takes everything a runner can reach: Actions secrets, the workflow token, cloud credentials and AI service keys. It then exchanges GitHub identity tokens for AWS, Google Cloud and Azure sessions, and can leave backdoors that survive a rotation, such as an AWS role opened to any account or a federated credential added to an Azure application. Accounts hit in October's GhostAction wave were far more likely to be reused, although Aikido does not attribute the two to the same actor. How the credentials were obtained is not explained. If any repository you can write to shows a pull request titled "docs: dependency audit notes" from Tuesday onward, treat the account and every secret that repository can read as compromised, and hunt for those cloud backdoors. The indicators are in the show notes.

ConnectWise has disabled five third-party extensions for ScreenConnect in partner environments after reports of unauthorised access, and says it has no evidence of a compromise of its own infrastructure or a flaw in ScreenConnect. Huntress reports attackers using cloud-hosted ScreenConnect panels to push commands that installed rogue clients on at least 288 endpoints across 48 organisations, first seen early yesterday Melbourne time. The payload, which Huntress calls SCKit, is built to spread back to any technician who connects to an infected machine and then to every endpoint that technician's panel can reach, although Huntress has not yet seen that jump succeed. Blackpoint Cyber says the toolkit tries a technique tied to an already patched ScreenConnect flaw, and in its test a current client didn't run the payload. As for how the attackers got in, Huntress now links the access to a flaw in a third-party extension, RMM+, which let attackers in without a key when none had been set, bypassing ScreenConnect logins and multi-factor authentication. ConnectWise had not confirmed an initial access vector when it disabled the extensions. Managed service providers should check ScreenConnect Run Command history even without alerts, disable the named extensions on premises, and patch clients.

A short update on N-able. The researcher behind the Able2Shell flaws says two new exploit chains work against Tuesday's hotfix, Hotfix 2. One gives unauthenticated code execution as root on the server, and the other runs commands as SYSTEM on managed Windows agents if the attacker knows the appliance ID. N-able says the server issue depends on the Legacy API being turned on and exposed to the internet, which is not the default, and hosted servers are not affected. Previdian, which has documented the server chain, recorded two exploitation attempts from a single address within hours of the release, and watchTowr reports probes too, with no successful exploitation seen so far. The second chain, against agents, rests on the researcher's claims as reported by The Hacker News and hasn't been independently checked. If you run N-central on premises, turn the Legacy API off today.

Australian focus.

The Bookeasy breach that paused Parks Victoria bookings is wider than first reported. Queensland Parks and Wildlife Service and South Australia's National Parks and Wildlife Service have both told customers that names, contact details and booking information may have been accessed, and in Western Australia the Shire of Carnarvon, which runs a visitor centre, has reported an incident involving the same provider. Bookeasy says it detected the activity in early November and has found no access to card details; payments run through a separate system. With summer camping season close, expect booking-themed phishing by email, text and WhatsApp, and confirm any request directly with the parks agency.

A brief follow-up on yesterday's hack of the Victorian Curriculum and Assessment Authority website: exams are going ahead as planned, and the authority's investigation continues.

Global threats.

Red Hat has fixed a critical flaw in its Quay container registry, rated 9.8, that lets an attacker add a signing key Quay will trust, then read or overwrite private images in every repository. With anonymous access on, which is the default, no account is needed, and turning anonymous access off does not protect you. A second flaw, rated 9.9, lets a user who can create a namespace steal other tenants' robot account tokens. Red Hat's advice is to block the keys endpoint at the proxy, search audit logs for key rotations with no expiry date, remove any keys you don't recognise, and install the fix, because until it is running a deleted key can simply be added again.

The Apache HTTP Server project has fixed a critical flaw in its HTTP/2 module, rated 9.8, that could let an unauthenticated attacker run code on the server. Only servers with HTTP/2 switched on are affected. Red Hat says public research has shown a reliable exploit, while Wiz says no exploit is available and no attacks have been reported, so the exploit status is disputed. The fixed release and distribution packages are in the show notes; if you can't update yet, removing HTTP/2 from the Protocols setting takes the server out of scope. Red Hat rates it Important rather than Critical for its own Enterprise Linux 9 and 10 packages, because their memory allocator makes exploitation harder. In a sign of the times, the flaw was first reported by Anthropic's open-source scanning service, and independently by Google.

Citrix has patched twelve flaws across NetScaler ADC, Gateway and Console. Most are memory bugs rated 9.3 or higher that can crash the appliance, and one in NetScaler Console, rated 9.4, lets an unauthenticated attacker bypass authentication. Citrix says it found them through an AI-assisted code review and knows of no exploits. Given NetScaler's history, patch before someone else reads the diff. Fixed builds are in the show notes.

A researcher who goes by MSNightmare has published SignDrop, a proof of concept that turns the log authentication feature Microsoft added to the Windows Common Log File System driver into a route from standard user to SYSTEM. Microsoft has not confirmed it, assigned a CVE or released a fix. One independent test says it works but is not reliable enough for operational use, and it is noisy at the keyboard. No attacks have been reported. Watch Microsoft's update guide, and don't switch the protection off, because that reopens the older flaws it was built to stop.

AI security.

Island has mapped 186 lookalike domains across 27 AI brands, including Claude, ChatGPT, Gemini, Copilot, Grok and Cursor, that send mistyped visits to fake verification pages, a browser-hijacking app or search-hijacking extensions. One route ends in a fake Cloudflare check that asks the user to paste a PowerShell command. Another delivers an app that is byte-for-byte the Microsoft Store version, signed by Microsoft, which Island says quietly takes over Chrome's search settings when the user is idle. The extension family has about 972,000 declared users. Bookmarking or managing approved AI tool addresses is cheaper than cleaning up after a typo.

Proofpoint has described BluePhishing, a variant of consent phishing aimed at Microsoft Entra Agent ID. Victims are talked into approving a malicious agent blueprint, which creates an agent identity in their tenant for the attacker. Proofpoint published the research on Monday and gives no victim numbers. Microsoft says that from this month ordinary Entra users can create agent blueprints by default, which widens the opening. The control is the same as for app consent: restrict who can grant consent to agents, and review agent identities you didn't create.

The GitHub stealer and the ScreenConnect toolkit both carry an AI angle as well: the stealer collects AI service keys from build runners, and Huntress says at least one SCKit script shows signs of being written with a language model. In both cases the harm comes from the access the attacker already had, not from the model.

Industry and patches.

It was a busy patch day elsewhere. Node.js fixed sixteen flaws, including HTTP/2 bugs that let an unauthenticated client crash a server or receive pieces of other connections' responses. MongoDB fixed a pre-authentication flaw that can crash a lagging replica set member when it is elected primary. PTC fixed a critical deserialisation flaw in Windchill and FlexPLM that could allow remote code execution. And Google Cloud says virtual machines on AMD's fifth-generation EPYC processors need a guest patch and a stop and start to fully address three side-channel flaws. Versions are in the show notes.

Outlook and patch priorities.

First, GitHub: search every organisation for the attacker's pull request title and branch names, rotate secrets in any affected repository, and check AWS, Azure and Google Cloud for the persistence the stealer leaves behind. Second, managed service providers on ScreenConnect: review Run Command history, disable the named extensions and update clients. Third, N-central on premises: Legacy API off now, and watch for N-able's next fix. Then Red Hat Quay, Apache servers with HTTP/2 enabled, and NetScaler. Locally, expect more parks and tourism operators to name Bookeasy, and treat booking messages with suspicion.
