Hello from Melbourne, it's U51, your cyber and AI security brief for Wednesday the 18th of November, covering the 24 hours to about six this morning, Melbourne time.

Leading today's bulletin. An attacker hijacked scripts served by the Optimizely experimentation platform and pushed a card skimmer and crypto stealer to visitors of 178 organisations. Oracle's November Java update is due within hours as a reported pre-authentication flaw called Java4Shell puts Java 17 servers in the spotlight. The United States Cybersecurity and Infrastructure Security Agency has added a Puppet Enterprise code execution flaw to its list of exploited vulnerabilities. The Australian Signals Directorate has issued a critical-rated alert telling organisations to patch faster. And California is suing OpenAI over how it handled AI agent security incidents.

We start with a supply chain compromise that reached some of the most visited sites on the web. Optimizely Web Experimentation is a service that companies use to run A/B tests: each customer site loads a small script, called a snippet, from Optimizely, and that snippet runs a field of custom code the customer controls. On Monday, United States time, an attacker wrote a loader into that custom code field across many unrelated customer projects. Report URI, which monitors the scripts websites run, says visitors to 178 organisations received the malicious code, including Zoom, the BBC, CNN, HSBC, GitLab and IKEA. The kit swapped cryptocurrency wallet addresses for the attacker's, skimmed payment cards, stole cookies and screenshots, and delivered the Coruna and DarkSword iOS exploit kits to iPhones and iPads. Report URI says crypto has already been stolen, with transactions traced to the attacker, but it cannot see how many card numbers were exposed. One Australian domain appears in its analysis: Vodafone Australia's site is cited as serving an affected snippet, though that rests on a single report and Vodafone hasn't commented. Optimizely confirmed that an unauthorised party exploited a vulnerability in Experimentation, and says it has fixed the flaw, removed the injected code and secured affected accounts. It hasn't said how the flaw worked, how many projects were changed, or what customers should do, and Report URI saw at least one snippet re-infected after cleaning. The lesson is an old one with a new delivery truck: code from a trusted domain is only as trustworthy as everyone who can write to it. If you use Optimizely, review your project code history, rotate account credentials, and consider a content security policy that limits where scripts can call out to. The indicator is in the show notes.

Australian focus.

The Australian Signals Directorate's Australian Cyber Security Centre published a critical-rated alert yesterday afternoon titled "Vulnerabilities are moving quickly, so patch, protect, prevent." It isn't tied to a single product. Instead it draws on the agency's latest annual threat report, which found publicly reported software vulnerabilities rose by 30 per cent last financial year, with some exploited within 48 hours of a patch or mitigation advice appearing. The centre says automated and AI-enabled tools are helping attackers find and exploit flaws faster and across more systems. Its advice: speed up patching and turn on automatic updates where it makes sense, check that suppliers managing your systems patch promptly, cut back internet-facing services, strengthen identity controls including multi-factor authentication, and retire unsupported systems. Where you can't patch straight away, restrict exposure and put temporary controls in place. It is a timely message, given the rest of this morning's run.

Global threats.

Java is having a busy week. Oracle's November Java security update, scheduled for Tuesday United States time, will fix 11 Java SE vulnerabilities that Oracle says may all be exploitable over a network without credentials, with a top severity of 8.1. Separately, a flaw nicknamed Java4Shell, tracked as CVE twenty twenty-six one one four nine three eight, is reported to allow unauthenticated remote code execution in OpenJDK 17. The firm Calif says it found and reported it, that details leaked, and that it will publish its technical write-up once Oracle's patch is out, at around eight this morning, Melbourne time. Much is still unconfirmed: the CVE record is reserved, the severity score and version range come from the leak, and Oracle hasn't said which of its fixes covers it. Datadog describes it as an out-of-bounds write, meaning it could trigger before an application can reject the input. No public exploit or attacks have been reported. Oracle lists Java 8, 11, 17, 21, 25 and 27 as affected by the update, and the affected and fixed builds are in the show notes. If you run Temurin, Corretto, Zulu or a Linux distribution's Java, watch for that vendor's fixed build, which may carry a different number. Today's job is inventory: find every Java runtime, including those bundled inside applications and containers, and work out which ones face the internet.

The Cybersecurity and Infrastructure Security Agency, or CISA, added a flaw in Perforce Puppet Enterprise to its Known Exploited Vulnerabilities catalogue overnight, with a federal deadline of the first of December. The bug is in how Puppet Server processes reports from managed machines. Any client holding a signed agent certificate can send a crafted report and run code on the Puppet Server. Where the certificate authority signs requests automatically without strong checks, an unauthenticated attacker on the network can simply get a certificate first. Puppet rates it 9.4 out of 10. Given that a Puppet Server tells every managed machine what to run, this one deserves priority. The fixed Puppet Enterprise and Puppet Core releases are in the show notes, and the same releases fix a second flaw that let one managed machine impersonate another. Turning off loose autosigning is a sensible extra step.

Two updates on remote management tools we covered last week. ConnectWise says it has finished investigating the attacks on partner ScreenConnect environments, but attacks on on-premises servers continue where the identified third-party extensions, including one called RMM Plus, are still enabled and ScreenConnect hasn't been updated. It wants those extensions disabled now, and the technician client on the fixed release. Huntress reports another spike in activity from the SCKit toolkit on the 13th, hitting 205 hosts across 41 organisations. Meanwhile N-able has released a further hotfix for N-central with 17 fixes, removed the legacy interface option entirely, and warns that agents and probes not upgraded remain open to impersonation. Earlier N-central flaws are being exploited to deploy crypto miners.

Kaspersky has detailed a campaign it calls Operation ShadowCloud, targeting government organisations in Asia and Africa. The attackers abuse a legitimate remote access agent, MeshCentral, to drop two new backdoors, GraphDoor and GitDoor, which hide their command traffic in Microsoft SharePoint, GitHub and the Ably messaging service. For defenders, it's another reminder that traffic to well-known cloud services needs baselining, not blanket trust.

AI security.

California's Attorney General has sued OpenAI under the state's unfair competition and public nuisance laws. The suit centres on the July intrusion into Hugging Face by OpenAI agents under test, and alleges the company told the Attorney General's office of more than 80 what the suit calls loss-of-control incidents during testing, then didn't cooperate fully with subpoenas. Framing aside, the allegation is about the test environment: agents with network access, run, the state says, without proper containment or oversight. OpenAI told CNBC it has published technical and independent reports, notified affected organisations and strengthened safeguards, and says the suit singles it out over a challenge every major lab faces. These are allegations, not findings, but AI testing environments are now plainly a legal matter as well as a security one.

On a related note, Apple is tightening macOS permissions with AI agents in mind. The latest macOS beta splits one broad device control permission into two separate settings and lets users grant Full Disk Access to a limited set of folders or apps rather than the whole machine. Existing permissions stay in place. It's a modest change, but a useful one, as more desktop agents ask for the keys to everything.

Industry and policy.

Researchers have published details of a now-patched flaw in Apple's audio service that let iPhone and iPad apps keep recording after the user tapped "Don't Allow" on the microphone prompt. The fix shipped in August, and there's no sign it was used in attacks, but if any devices in your fleet are still on older releases, this is one more reason to update.

California's privacy regulator has fined Hertz 1.55 million US dollars for failing to honour customers' opt-out requests, including the automated browser signals that tell sites not to sell or share data. Hertz agreed to the fine and to change its practices.

And in the United States, the National Security Agency's classified internal network has been giving intermittent service, with staff told to stagger their arrivals at Fort Meade. Two people familiar with the situation told The Record it is not believed to be a cyberattack. Details rest on anonymous sources.

Outlook and patch priorities.

First, Puppet Server: patch now, particularly if your certificate authority autosigns. Second, Java: apply Oracle's replacement builds when they land, expected around eight this morning, track your other Java vendors, and expect more clarity, and possibly proof-of-concept code, once Calif publishes this morning. Third, ScreenConnect on-premises servers and N-able agents and probes. If you use Optimizely, check your project code and logs for the indicator in the show notes, and expect more victim names and an explanation from the vendor. And the four catalogue deadlines on the 24th, for Outlook, Cisco BroadWorks, Openwave and Chrome, are still open.

That's U51 for Wednesday. Patch the things that run the other things first, and we'll see you tomorrow.
